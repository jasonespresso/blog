Understanding the Architecture

Plex works as a client–server system. Your iMac running High Sierra is the server: it hosts Plex Media Server, catalogues your files, manages metadata, and — when necessary — converts video in real time for whatever is asking to play it. Your Apple TV is the client: it asks the server for content and renders it on screen.

The distinction matters because almost every setting you'll encounter lives on one side or the other. Settings on the server control how your library is managed, how video is processed, and how Plex reaches the wider internet. Settings on the Apple TV control how that content is presented and played back to you specifically.

Key Principle When something goes wrong — choppy playback, missing metadata, a film that won't load — start by asking which side of this divide the problem lives on. Most answers follow from there.

The Plex Web Interface

On your iMac, the primary way to manage the server is through Plex Web: open any browser and go to http://localhost:32400/web. This is where library management, server settings, and metadata editing all happen. You can reach the same interface from any machine on your network by replacing localhost with your iMac's local IP address.

Building Your Libraries

A library in Plex is a named collection of a single content type — Movies, TV Shows, Music, Photos — pointing to one or more folders on your iMac. Getting your library structure right from the beginning saves a great deal of remedial effort later.

File Naming: The Foundation of Everything

Plex identifies your media by matching filenames against its metadata agents (primarily The Movie Database for films, TheTVDB for television). The cleaner your filenames, the more reliably this works.

Films Name files as: Movie Title (Year).mkv
Example: Andrei Rublev (1966).mkv
TV Shows Organise as: Show Name/Season 01/Show Name - S01E03 - Episode Title.mkv
The season subfolder is not strictly required, but it keeps things tidy and Plex expects it.

Adding a Library

  1. In Plex Web, click the + icon beside Libraries in the left sidebar.
  2. Choose the content type: Movies, TV Shows, Music, etc.
  3. Give the library a name you'll recognise.
  4. Click Add folders and navigate to the relevant folder on your iMac.
  5. Under Advanced, review the agent and scanner — the defaults are almost always correct.
  6. Click Add Library. Plex will begin scanning and fetching metadata immediately.
Tip You can add multiple folders to a single library — useful if your films are spread across an internal drive and an external. Plex treats them as one unified collection.

Library Scanning

Plex does not watch your folders in real time by default on all systems. If you add new files and they don't appear, go to the library in Plex Web, click the … menu, and choose Scan Library Files. You can also force a full metadata refresh from the same menu.

Server Settings

The server settings live at:

Plex Web › Settings (wrench icon) › left sidebar

The categories below cover the ones most relevant to everyday use on a High Sierra iMac.

General

Friendly Name

The name shown on your Apple TV when choosing a server. Change it from the default so it's immediately identifiable — your name, or a room, works well.

Send crash reports

Leave this on if you want Plex to automatically report problems — helpful for debugging obscure playback issues in future updates.

Enable Plex Media Server debug logging

Leave off during normal use. Turn on temporarily only if troubleshooting a specific, reproducible problem.

Remote Access

This section controls whether Plex can be reached from outside your home network. See the dedicated Remote Access section for a full discussion.

Agents

Agents are the services Plex consults to fetch artwork, descriptions, cast, and ratings. You can adjust the priority order for each content type — dragging sources up and down the list tells Plex which to prefer when they conflict. The Movie Database and TheTVDB are the best primary sources for most collections.

Library

Scan my library automatically

Tells Plex to watch for new files. On High Sierra this works via a periodic scan rather than a filesystem watcher. Recommended: on.

Run a partial scan when changes are detected

More efficient than a full scan. Leave this on.

Empty trash automatically after every scan

If you delete a file from disk, Plex will remove its entry from the library automatically. Recommended for keeping the library tidy.

Generate video preview thumbnails

Creates a strip of thumbnail images for the seek bar. Visually elegant but demands significant processing time and disk space. Set to as a scheduled task so it runs when you're not using the machine.

Generate chapter images

Similar to preview thumbnails — useful, but resource-intensive. Schedule it.

Network

Enable local network discovery (GDM)

Allows your Apple TV to find the server automatically. Keep this on — without it, you'd need to connect manually by IP address.

Strict TLS configuration

For a home setup, the default here is fine. Only adjust if you have specific security requirements.

Preferred network interface

If your iMac has both Wi-Fi and Ethernet active, you can specify which to use for Plex. Ethernet is more reliable for a server — select it if you're wired in.

Media Quality & Transcoding

This is the single most consequential area of Plex configuration, and it's worth understanding what's actually happening.

When your Apple TV requests a video, Plex first checks whether it can play the file as-is — this is called direct play. If the video codec, audio codec, or container format isn't supported natively, Plex converts it in real time — this is transcoding. Transcoding is handled entirely by your iMac, which is why its processor matters: a High Sierra iMac from 2017 onwards handles 1080p transcoding comfortably, while 4K transcoding can be demanding.

Transcoding Settings

Settings › Transcoder

Transcoder quality

Higher quality means more CPU usage. Make my CPU hurt produces the best image but may cause dropped frames on less powerful iMacs. Automatic is a safe, balanced starting point.

Transcoder temporary directory

Where Plex writes temporary files during conversion. By default this is on your system drive. If disk space is tight, redirect it to an external drive.

Background transcoding x264 preset

Controls the speed–quality trade-off for background tasks. The default is fine; only adjust if your iMac struggles under load.

Enable HDR tone mapping

If you have HDR source files, this converts them to SDR for displays that don't support HDR. Computationally expensive; test before leaving on.

High Sierra Note macOS High Sierra does not support hardware-accelerated transcoding via Plex's built-in mechanisms in the same way later macOS versions do. The iMac's CPU will handle all transcoding work. This is usually sufficient for one or two simultaneous streams at 1080p.

Maximising Direct Play

The best way to reduce transcoding load is to ensure your media is in formats the Apple TV can handle natively: H.264 video in an MKV or MP4 container, with AAC or AC3 audio. If you're ripping your own discs, encoding to H.264/AAC will almost always direct play without any conversion.

H.265 (HEVC) content can direct play on Apple TV 4K with the right Plex Pass settings, but may transcode on older models. If you have a mixed collection, this is worth checking.

Apple TV Playback

The Plex app on Apple TV has its own set of settings, separate from — and sometimes interacting with — the server settings on your iMac. To access them, open the Plex app and navigate to:

Plex App › Settings (gear icon, bottom of sidebar)

Video Quality

This is the most important client-side setting. It controls the maximum quality Plex will attempt to stream to your Apple TV.

Local Quality

The quality used when your Apple TV and iMac are on the same network. Set this to Original or Maximum — there is no bandwidth reason to reduce it at home, and doing so will force unnecessary transcoding.

Remote Quality

Used when accessing Plex from outside your home. Lower settings reduce data usage on mobile connections. 4 Mbps 720p or 8 Mbps 1080p are reasonable defaults for most broadband connections.

Tip: The "Original" Setting Setting Local Quality to Original tells Plex to attempt direct play first, and only transcode if there's no other option. This is almost always what you want on a home network. If a film stutters at this setting, it's typically a network issue, not a quality setting to reduce.

Audio

Audio Boost

Amplifies the audio stream during transcoding. Useful if the volume feels low, particularly for older films. Has no effect during direct play.

Normalise Multi-Channel Audio

Reduces the volume difference between loud and quiet passages. Helpful late at night; best left off for critical listening.

Subtitles

Plex handles subtitles in two ways. Embedded subtitles are stored inside the video file and are the most reliable. External subtitles are separate .srt or .ass files in the same folder, named to match the video. Plex also supports downloading subtitles automatically via OpenSubtitles if you connect your account in server settings.

Subtitle Size

Adjustable in the Plex app. The default is readable at a normal viewing distance; increase if your TV is smaller or you sit further back.

Burn-in Subtitles

Forces subtitles to be rendered directly onto the video frame during transcoding. Only needed for image-based subtitles (common on Blu-ray rips) that the Apple TV can't otherwise display.

Navigation & Display

Online Content

Controls whether free, ad-supported Plex content (films and TV) appears in your interface. Disable if you want only your own library visible — it keeps the experience cleaner.

Continue Watching

The row of in-progress titles on the home screen. Useful as a default view; can be removed from the home screen customisation if you prefer browsing by library.

Customising the Home Screen

On the Apple TV app, you can rearrange and remove rows from the Plex home screen. Long-press on a row's title with the remote to move or hide it. Pin your most-used libraries to the top and remove content rows you don't use — the result is a much more purposeful, personal interface.

Organisation & Metadata

One of Plex's great pleasures is a well-organised library — each film with its correct poster, the right year, a clean synopsis. Metadata is fetched automatically during scanning, but it requires human oversight for anything unusual.

Fixing a Misidentified Title

  1. In Plex Web, navigate to the item and click the pencil (edit) icon.
  2. Select Fix Incorrect Match.
  3. Search by title, year, or ID to find the correct entry.
  4. Confirm the match. Plex will re-fetch all metadata and artwork.

Collections

Collections let you group related films — a director's work, a franchise, films from a particular country — without creating separate libraries. Add a film to a collection via its edit menu. Collections appear as a single entry in the library, expanding when selected.

Playlists

Playlists are ordered, manually curated queues — useful for a film night sequence, a music album, or a marathon. Create them in Plex Web via Playlists in the left sidebar, then access them from any client including your Apple TV.

Artwork

Plex fetches multiple poster and backdrop options from its metadata sources. If the default artwork isn't to your taste, click the edit icon on any item and choose Poster or Art to see all available options — or upload your own. Custom artwork you upload is stored locally and survives library refreshes.

Tip: Local Assets If you place a file named poster.jpg in the same folder as a film, Plex will use it automatically without needing to upload through the interface. Useful for films with unusual artwork requirements.

Remote Access

Plex can make your library available outside your home network — on a phone, a friend's Apple TV, or anywhere with a browser. This requires your iMac to be accessible from the internet, which Plex handles through a relay service unless you configure direct connections.

How It Works

By default, when remote access is enabled, Plex attempts to open a port on your router via UPnP and register your server's external address with Plex's cloud. Clients outside your network are directed to connect to your iMac's public IP address on that port.

Settings › Remote Access

Enable Remote Access

The master switch. When the status shows "Fully accessible outside your network," the relay is working. A warning here usually means a router configuration issue.

Manually specify public port

If UPnP is unreliable on your router, specify a port (32400 is the default) and manually forward it in your router's settings. More reliable than automatic discovery.

Relay

If direct connections fail, Plex routes traffic through its own servers. Quality is limited (typically 2 Mbps) but requires no router configuration. Useful as a fallback; not ideal for high-quality remote streaming.

High Sierra Consideration Make sure macOS's built-in firewall (System Preferences → Security & Privacy → Firewall) is either off or explicitly permitting Plex Media Server. A blocked firewall is the most common reason remote access fails on a Mac.

Maintenance & Health

A Plex server kept in good repair runs reliably for years. These are the practices worth building into your routine.

Scheduled Tasks

Settings › Scheduled Tasks

Plex can run maintenance jobs — refreshing metadata, analysing files for audio loudness, generating thumbnails — on a schedule. The default window is between 2am and 5am. You can adjust this to any quiet period when your iMac is likely to be awake but idle. Each task can be enabled or disabled independently.

Cleaning the Database

Over time, Plex's database accumulates entries for files you've moved or deleted. Run Clean Bundles and Empty Trash from the Troubleshooting section periodically — monthly is sufficient for most collections.

Settings › Troubleshooting › Clean Bundles / Empty Trash

Updating Plex Media Server

When an update is available, Plex will notify you within the web interface. On High Sierra, you can update by downloading the new version from plex.tv/media-server-downloads and running the installer — it replaces the existing installation without affecting your library or settings.

Tip: Before Updating Note your current version number before updating. If a new release introduces a problem, knowing the previous version makes it easy to roll back.

Keeping the iMac Awake

Plex cannot serve content if your iMac is asleep. Go to System Preferences → Energy Saver and either disable sleep entirely, or set the computer sleep timer to Never while leaving the display sleep as you prefer. You can also enable Wake for network access, which allows the iMac to wake when a client requests something — though this has a small delay and is less reliable than simply keeping it awake.

The Logs

If something breaks unexpectedly, Plex's log files are the first place to look. They're accessible from the web interface under:

Settings › Troubleshooting › Download Logs

The relevant file is usually Plex Media Server.log. Search it for ERROR or WARNING lines corresponding to the time the problem occurred.

Plex Pass

Plex's free tier is generous — full library management, streaming to any client, remote access. Plex Pass is the optional paid upgrade, available as a monthly subscription or a one-time lifetime purchase. The features it unlocks that are most relevant to your setup:

Hardware-Accelerated Transcoding

Offloads conversion to the GPU rather than the CPU. On High Sierra this is limited, but it can reduce CPU load for supported codecs.

Offline Sync

Download content to your devices for watching without a server connection. Useful for travel.

Lyrics

Synced lyrics display for music libraries.

Live TV & DVR

Requires a compatible USB tuner and antenna, but turns Plex into a fully functional DVR. Outside the scope of this guide but worth knowing exists.

Multi-User Home

Create separate managed accounts with their own watch histories, watch lists, and — for younger viewers — content restrictions.

Skip Intro

Plex detects and can skip TV show intro sequences automatically during continuous playback.

The lifetime pass pays for itself quickly if you use Plex seriously — particularly the multi-user and hardware transcoding features. But the free tier is sufficient for most single-household setups streaming from a local collection.

Final Tips

A few principles, gathered from experience, that don't fit neatly into any one settings screen:

Wired is always better than wireless for the server. If your iMac is near your router, an Ethernet cable eliminates an entire category of potential streaming problems. Your Apple TV can remain on Wi-Fi without issue — the bottleneck is almost never the last hop to the TV.

Give your media consistent, tidy filenames from the start. The temptation when building a library is to import everything quickly and fix it later. Later rarely comes. Ten minutes spent correctly naming a new film before adding it saves an hour of remedial metadata fixing down the line.

Direct play is the goal; transcoding is the fallback. If a film is transcoding on a local network when it doesn't need to be, something in the chain is wrong — usually the quality setting on the Apple TV, or a subtitle format forcing a transcode. Investigating and resolving this once is worth the effort.

The Plex forums are exceptionally good. The community at forums.plex.tv has addressed nearly every problem you're likely to encounter. Searching there before raising a support ticket will usually produce a faster answer.

Back up your Plex data directory. Your library metadata, custom artwork, playlists, and watch history are stored in a single folder: ~/Library/Application Support/Plex Media Server/. Backing this up means a new installation or a fresh hard drive won't lose any of that accumulated work.

One Last Thing Plex rewards a little attention to setup and then largely takes care of itself. The most satisfying version of this system is one you don't have to think about — where selecting a film on your Apple TV simply works, beautifully and reliably, every time.
